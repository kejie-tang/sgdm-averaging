## Code & Data Disclosure

> All numerical results in the paper are produced by the code in the
> accompanying repository. The simulation experiments (quadratic loss, logistic
> loss, and the sensitivity / asymptotic-normality studies) use only synthetic
> data generated in-code from the seeds and parameter values described in the
> paper; no external data files are required. The real-data experiments use the
> public MNIST (LeCun et al., <http://yann.lecun.com/exdb/mnist/>) and CIFAR-10
> (Krizhevsky et al., <https://www.cs.toronto.edu/~kriz/cifar.html>) datasets.
> Both are freely available and are not redistributed by the authors.
>
> Two kinds of data files accompany the code. (i) The per-iteration
> training-loss series behind Figure 16 (CIFAR-10) are archived in
> `data/cifar_logs/`; they are the series the published panel is drawn from,
> and `src/cifar/cifar_experiment.py` redraws that panel from them. (ii) The
> public MNIST and CIFAR-10 datasets are downloaded on demand and are not
> redistributed.
>
> Repository: <https://anonymous.4open.science/r/sgdm-averaging-2F7D>
> (also provided as a supplementary archive `sgdm-averaging.tar.gz`, built by
> `scripts/make_tarball.sh`).

## Data Availability

> The datasets analysed are either generated by the provided code (synthetic
> simulations) or publicly available (MNIST,
> <http://yann.lecun.com/exdb/mnist/>; CIFAR-10,
> <https://www.cs.toronto.edu/~kriz/cifar.html>). No new datasets were created.
> The public datasets are fetched automatically, with
> `python src/mnist/mnist_experiment.py --download` and
> `python src/cifar/cifar_experiment.py --mode train --download`.
>
> The one exception is Figure 16: its published panel is drawn from the
> per-iteration training-loss series recorded by our original CIFAR-10
> training run, which are distributed with the code in `data/cifar_logs/`
> (4 momentum weights x 3 seeds x 19,550 iterations, plain CSV). No other
> result data are distributed.

## Code Availability

> The code reproducing all figures and tables is available at
> <https://anonymous.4open.science/r/sgdm-averaging-2F7D>. A frozen copy is
> included as supplementary material.

## Reproducibility

> Every experiment is fully reproducible from the provided code. All random
> number generators are seeded per replication, and SGD and SGDM share the same
> pre-sampled mini-batch sequence within each replication. The script for each
> figure, with its exact parameters, is listed in `README.md` (Sections 4-5).

## Repository layout

Per the OR journal instructions
(<https://orjournal.github.io/InstructionsForAuthors.html>): a top-level
`README.md` (environment, hardware/software, data, per-figure commands),
`LICENSE` (MIT) and `AUTHORS`, `src/` (one script per figure group, sharing
`src/sgdm_core.py`), `scripts/run_all.sh`, `data/` (the archived Figure-16
training logs plus a note on where the public MNIST / CIFAR-10 files come
from), and `docs/` (these statements). Running the scripts creates
`results/<exp>/` with the figure for each panel and the raw `*.npz` arrays
behind it; that directory is generated output and is not tracked here. Include
it when packing the submission tarball — the OR instructions list `results`
among the recommended sub-directories ("should contain any raw results from the
paper, as well as any plots or figures"), which the tarball satisfies even
though the repository itself does not carry the files.

`bash scripts/make_tarball.sh` builds that archive: the files above plus
`results/`, with the 295 MB of public MNIST / CIFAR-10 downloads left out.
It prints the size and refuses to finish if anything is missing or if a
dataset leaked in. `RAW=0` gives a figure-only archive (~4 MB instead of
~126 MB) for a submission system with a size cap.
