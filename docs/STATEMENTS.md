## Code and Data Disclosure

> All numerical results in the paper are produced by the code in the
> accompanying repository. The simulation experiments (quadratic loss,
> logistic loss, and the sensitivity / asymptotic-normality studies) use only
> synthetic data that are generated in-code from the seeds and parameter
> values described in Section 6 of the paper; no external data files are
> required. The real-data experiment uses the public MNIST dataset
> (LeCun et al.), which is freely available at
> http://yann.lecun.com/exdb/mnist/ and is not redistributed by the authors.
>
> Repository: <GITHUB_URL>
> (also provided as a supplementary archive `code_release.zip`).

## Data Availability Statement

> The datasets analysed during the current study are either generated by the
> code provided (synthetic simulations) or are publicly available (MNIST,
> http://yann.lecun.com/exdb/mnist/). No new datasets were created and no data
> files are distributed with the code; the MNIST data can be obtained from the
> public source above or fetched automatically by the provided script
> (`python src/mnist/mnist_experiment.py --download`).

## Code Availability Statement

> The code reproducing all figures and tables is available in the repository
> <GITHUB_URL>. A frozen copy is included as supplementary material.

## Reproducibility statement

> Every experiment is fully reproducible from the provided code. All random
> number generators are seeded per replication, and SGD and SGDM share the
> same pre-sampled mini-batch sequence within each replication. The mapping
> from each figure in the paper to the script that generates it, together with
> the exact parameter values, is given in `README.md` (Section 4 and the
> Figure-to-code table in Section 5).

## Suggested repository layout for the journal (per OR journal instructions)

The INFORMS guidance (https://orjournal.github.io/InstructionsForAuthors.html)
recommends organizing code so that a reader can reproduce each reported
result. This repository follows that recommendation:

* a top-level `README.md` with environment, hardware/software, data, and
  per-figure run commands;
* a `LICENSE` (MIT) and `AUTHORS` file, as required by the INFORMS guidelines;
* a `src/` directory split by experiment, one script per figure group;
* a shared `src/sgdm_core.py` so all experiments use identical conventions;
* a `scripts/` directory with `run_all.sh` for one-command reproduction;
* a `data/` directory that **documents where the public MNIST files come from**
  (no data files are committed); and
* a `docs/` directory with these statements; and
* a `results/` directory that holds the paper's figures, the raw numeric
  arrays, and the authors' run logs.

## Steps to produce a GitHub repository from this folder

```bash
cd code_release
git init
git add .
git commit -m "Code and data for SGDM averaging paper"
git branch -M main
git remote add origin <GITHUB_URL>
git push -u origin main
```

Then replace `<GITHUB_URL>` above and in the manuscript with the real URL.
