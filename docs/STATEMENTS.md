## Code & Data Disclosure

> All numerical results in the paper are produced by the code in the
> accompanying repository. The simulation experiments (quadratic loss, logistic
> loss, and the sensitivity / asymptotic-normality studies) use only synthetic
> data generated in-code from the seeds and parameter values described in the
> paper; no external data files are required. The real-data experiment uses the
> public MNIST dataset (LeCun et al.), freely available at
> <http://yann.lecun.com/exdb/mnist/> and not redistributed by the authors.
>
> Repository: <https://github.com/kejie-tang/sgdm-averaging>
> (also provided as a supplementary archive `code_release.zip`).

## Data Availability

> The datasets analysed are either generated by the provided code (synthetic
> simulations) or publicly available (MNIST,
> <http://yann.lecun.com/exdb/mnist/>). No new datasets were created and no data
> files are distributed; MNIST is fetched automatically by
> `python src/mnist/mnist_experiment.py --download`.

## Code Availability

> The code reproducing all figures and tables is available at
> <https://github.com/kejie-tang/sgdm-averaging>. A frozen copy is included as
> supplementary material.

## Reproducibility

> Every experiment is fully reproducible from the provided code. All random
> number generators are seeded per replication, and SGD and SGDM share the same
> pre-sampled mini-batch sequence within each replication. The script for each
> figure, with its exact parameters, is listed in `README.md` (Sections 4-5).

## Repository layout

Per the OR journal instructions
(<https://orjournal.github.io/InstructionsForAuthors.html>): a top-level
`README.md` (environment, hardware/software, data, per-figure commands),
`LICENSE` (MIT) and `AUTHORS`, `src/` (one script per figure group, sharing
`src/sgdm_core.py`), `scripts/run_all.sh`, `data/` (documents the public MNIST
source; nothing committed), `docs/` (these statements), and `results/` (figures,
raw arrays, run logs).

## Anonymous link (optional)

<https://anonymous.4open.science/> builds a read-only, term-redacted mirror and
returns a random slug (e.g. `https://anonymous.4open.science/r/840c8c57-...`).
Nothing about the account is exposed and the mirror can be set to expire after
the review round. If used, give reviewers the slug instead of the GitHub URL.

Alternatively, upload `code_release.zip` as supplementary material — no URL is
exposed, though reviewers cannot browse it as conveniently.

## Checklist before pushing

```bash
TERMS="surname1|surname2|university|department|institute-abbrev"

# 1. no names / affiliations / e-mails in the files
grep -rniE "$TERMS" --include="*.md" --include="*.py" --include="*.sh" .

# 2. no names in the git history
git log --all --format="%an <%ae> %s" | grep -iE "$TERMS"

# 3. no local absolute paths (would leak a user name)
grep -rnE "/Users/|/home/|[A-Z]:\\\\Users" --include="*.py" --include="*.sh" .
```

History is rewritten with

```bash
git filter-branch -f --env-filter '
export GIT_AUTHOR_NAME="Anonymous Authors"
export GIT_AUTHOR_EMAIL="anonymous@example.com"
export GIT_COMMITTER_NAME="Anonymous Authors"
export GIT_COMMITTER_EMAIL="anonymous@example.com"
' -- --all
rm -rf .git/refs/original
git reflog expire --expire=now --all && git gc --prune=now
```

(already applied — every commit is authored by "Anonymous Authors
<anonymous@example.com>").
